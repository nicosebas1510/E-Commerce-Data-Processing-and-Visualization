# E-Commerce-Data-Processing-and-Visualization

Proyek ini bertujuan untuk merancang struktur basis data tingkat lanjut (Data Warehouse / Star Schema) dan membangun dashboard interaktif untuk menganalisis kinerja penjualan e-commerce (menggunakan *Olist Brazilian E-Commerce Dataset*).

Proyek end-to-end ini mencakup perancangan model data dimensional, ekstraksi dan transformasi data (ETL) menggunakan SQL di MySQL, perhitungan metrik bisnis (KPI) via DAX, hingga visualisasi data interaktif di Power BI.

---
# Tech Stack & Tools
**Data Modeling & Transformation:** Power Query & Spreadsheet (Data Cleaning, Schema Setup)

**Business Intelligence & Analytics:** Power BI Desktop (DAX Measures, Data Modeling, & Interactive Dashboarding)

**Source Dataset:** Olist Brazilian E-Commerce Public Dataset (Kaggle)
